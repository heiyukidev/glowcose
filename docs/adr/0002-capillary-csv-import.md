# Capillary CSV import only

Glowcose can ingest a myDiabby CSV as Readings after the Member confirms Correspondence. Import is web-only until a store build adds a native file picker; an Expo OTA cannot add that picker. Only capillary glucose rows are admitted; CGM cadence and CGM or insulin-only exports are refused. Context comes from type-meal / post-prandial columns when assigned, otherwise from a text context column or time of day. Duplicate live Readings (same Carnet, `takenAt`, `valueMgDl`) are skipped so a second import does not double the log. A Reading is a fingerstick observation — treating a Libre stream as Readings would make today, the chart, and colour bands unreadable.
